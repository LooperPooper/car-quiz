# Угадай марку

Викторина для малыша: взрослый называет марку автомобиля, ребёнок выбирает логотип из четырёх.

- `index.html` — исходник игры
- `build.py` — собирает `docs/` (сайт для GitHub Pages, работает офлайн) и `CarQuiz.html` (один файл)
- `logos-small/` — логотипы из [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset)

После правок в `index.html`: `python build.py`, затем закоммитить и запушить.
Только для личного использования; логотипы — товарные знаки их владельцев.
